# 策划工作台

[打开方案文档 v2.0](方案文档/README.md)

当前已完成中文方案文档整理和功能目录规划，应用尚未实现。`apps/`、`packages/`、`tests/`、`scripts/`、`config-examples/` 是后续开发使用的目录骨架，尚无可运行程序。

新版方案采用本地白名单文件登录，不依赖 GitLab、Google 或其他第三方账号及存储；富文本编辑体验参考飞书，网页工作台采用左侧关系图、右侧分类卡片布局。功能范围与验收标准以新版方案为准。

根目录的[游戏策划工作台开发计划.md](游戏策划工作台开发计划.md)为历史原版，其第三方登录和存储路线已由新版方案取代；根目录[原始图例](68efdb4ff392c4867891eb9e9b9c5810.jpg)保持不变。方案文档中的参考图是上传副本，不覆盖根目录原图。

[功能目录与代码映射](方案文档/08-项目目录/功能文件夹与代码映射.md)说明各开发目录用途。空目录通过 `.gitkeep` 保留。`策划案/` 包含策划案、可玩 HTML 原型、界面 SVG 和配置表样例。

仓库不包含真实身份、凭据、权限配置或运行数据。运行数据路径待部署时确定，本地凭据、运行数据、依赖和生成产物由 `.gitignore` 排除。
