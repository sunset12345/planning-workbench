# 策划工作空间

这里集中管理玩法策划案、策划 Skill，以及策划工作台的开发资料。日常整理功能需求从“策划案”或“策划技能”进入。

## 常用入口

| 要做的事 | 入口 |
| --- | --- |
| 阅读当前玩法策划案 | [搜打撤 / 远征融合玩法](策划案/搜打撤远征融合玩法/融合玩法策划案.html) |
| 体验玩法原型 | [可玩原型](策划案/搜打撤远征融合玩法/可玩原型.html) |
| 查看功能需求检查与待确认项 | [检查与补充草案](策划案/搜打撤远征融合玩法/评审记录/功能需求检查与补充草案.html) |
| 使用或修改策划 Skill | [技能说明](策划技能/README.md) · [Skill 正文](策划技能/game-feature-planning/SKILL.md) |
| 套用策划案模板 | [功能策划案模板](策划技能/game-feature-planning/assets/功能策划案模板.md) |
| 查看工作台开发方案 | [工作台开发](工作台开发/README.md) |
| 查找历史原件、上传副本及未分类图片 | [资料归档](资料归档/README.md) |

## 目录用途

```text
planning-workbench/
├─ README.md
├─ 策划案/                  # 按玩法/功能组织正文、原型、UI、配置和评审
├─ 策划技能/                # 可编辑 Skill、模板、参考规范和发布包
├─ 工作台开发/              # 工作台软件的方案、代码骨架和测试目录
└─ 资料归档/                # 历史原件、上传副本及待确认用途的图片
```

策划案聚焦当前功能需求：功能条件、规则、玩家操作、UI 反馈和配置字段。工作台的软件架构与开发方案集中在“工作台开发”，单独维护。

工作台应用尚未实现，没有启动命令或可运行服务；可直接打开的 HTML 是玩法原型及文档。

## 后续文件放在哪里

- 新玩法或新功能：在 `策划案/` 下建立对应目录，关联的 UI、配置、原型和评审记录放在该目录内。
- 策划规范与模板：维护 `策划技能/game-feature-planning/`；对外使用的 ZIP 放在 `策划技能/发布包/`。
- 工作台代码、配置示例和测试：分别放在 `工作台开发/` 下已有的开发目录。
- 历史资料保留来源；用途未确认的上传文件先放 `资料归档/未归类图片/`，明确归属后再迁入功能目录。

本次迁移对应关系见[目录整理记录](资料归档/目录整理记录.md)。
