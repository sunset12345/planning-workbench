# 开发计划与范围

## 1. 目标

建设面向策划、开发、美术、测试的本地优先网页工作台。核心流程：上传资料 → 预览转换 → 选择项目/系统/功能 → 分类卡片阅读 → 完整正文 → 在线编辑保存 → 搜索定位 → 查看历史。

保留原图浅色背景、左关系图、右分类卡片的组织方式。卡片不是正文替代品，任何卡片均能进入完整文档，正文支持阅读/编辑模式切换。

## 2. 实施路线

| 阶段 | 目标 | 存储与权限 | 退出条件 |
| --- | --- | --- | --- |
| P0 交互原型 | 验证页面结构、图谱联动、正文编辑手感 | 可以临时使用内存/IndexedDB；演示账号仅作 UI 占位，不是安全登录 | 关键流程被负责人确认；有样例包导出 |
| P1 本机可用版 | 实际资料持久化、基本白名单、导入编辑搜索版本 | 本地服务端 + SQLite + 磁盘资源；默认仅监听回环地址 | 重启不丢数据，保存冲突、恢复和权限用例通过 |
| P2 局域网团队版 | 项目成员隔离、会话管理、更新提示、部署备份 | 同一服务端集中写入；局域网 TLS 与防火墙配置；文件不直接暴露 | 多人冲突、越权测试和备份恢复通过 |
| P3 按需求扩展 | 评论增强、实时共同编辑、丰富导出 | 另行设计协同协议、迁移和授权 | 每项单独评估和验收 |

P0 可与 P1 连续开发，避免把浏览器存储当正式数据源。P1 不等待 GitLab/Google 选择，不开发其 OAuth 或同步适配器。局域网多人并不意味着实时同时编辑；首版采用版本冲突检测。

## 3. 首个可用版本的功能

- 项目、系统、功能、策划文档及显式关系管理。
- 统一分类模板、缺项提示、填写状态和完整正文；旧资料可保持原结构。
- 标题、段落、列表、表格、图片、链接、代码块、引用、任务项等块编辑；保存状态可见。
- Markdown/DOCX 转换编辑；XLSX 只读预览；图片、XMind 源文件和配套预览。
- 标题、正文、配置字段及附件名称检索，命中定位到稳定章节/块。
- 本地白名单及项目角色；自动保存、手动保存、版本历史和冲突保护。
- 完整项目包导出导入、备份恢复操作说明。

## 4. 明确不纳入首版

飞书所有功能等价复刻、在线 Excel 公式计算、编辑 XMind 内部节点、AI 问答、自动推断业务依赖、第三方账户登录、Git/云盘同步、实时共同编辑、外部通知推送、公共分享链接。

评论可以纳入 P2；P1 以“待确认事项”章节承载问题记录，不把它宣称为评论系统。工作台原图中的 Cursor API、模型设置、会话等入口与本轮需求无直接关系，首版不照搬。

## 5. 成功定义

资料只有一份权威正文，多个视图定位一致；本地服务重启后资料仍在；失败和冲突不吞字；阅读者无法用 API 或附件地址绕过权限；文件转换不静默丢失信息；团队知道哪些能力已验收、哪些仍为计划。
