# 策划工作台开发资料

当前为方案和目录骨架，尚无可运行应用。此目录集中保存工作台软件本身的设计与后续开发文件。

[阅读方案文档 v2.0](方案文档/README.md) · [目录与功能映射](方案文档/08-项目目录/功能文件夹与代码映射.md)

| 目录 | 用途 | 当前状态 |
| --- | --- | --- |
| `方案文档/` | 工作台范围、编辑器、图谱、数据与实施方案 | 已有方案 |
| `apps/web/` | 网页工作台 | 空目录骨架 |
| `apps/server/` | 工作台服务 | 空目录骨架 |
| `packages/` | 共享契约与文档结构 | 空目录骨架 |
| `tests/` | 单元、集成、端到端测试及样例 | 空目录骨架 |
| `scripts/` | 后续开发辅助脚本 | 空目录骨架 |
| `config-examples/` | 不含真实凭据的配置示例 | 空目录骨架 |

空目录由 `.gitkeep` 保留。技术目录的相对根为本目录；目前没有脚本或构建配置需要修改工作目录。将来添加启动、构建流程时，应明确从此目录执行。

历史 v1 计划与参考图在[资料归档](../资料归档/README.md)。旧登录、存储路线仅作历史参考，工作台当前方案以 v2.0 为准。
