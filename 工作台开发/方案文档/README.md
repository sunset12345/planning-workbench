## 已确定与默认建议

- 已确定：先做可操作原型；支持上传、分类、图谱、全文阅读、在线编辑；本地白名单登录；不用 Git 等第三方账号。
- 建议默认：React + TypeScript 前端，本地 Node.js 服务端，SQLite 保存结构化正文及元数据，磁盘保存资源原件。选型细节在开发前锁定版本。
- 默认先做本机单人完整闭环，再验收局域网多人模式；前端和后端契约从一开始统一。
- 纯静态 HTML 可作视觉演示，不能承担可信身份认证、权限隔离或团队正式存储。
