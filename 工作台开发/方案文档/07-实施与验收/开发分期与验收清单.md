# 开发分期与验收清单

## 1. 按依赖实施

| 顺序 | 交付物 | 验收后再推进 |
| --- | --- | --- |
| 1 结构与界面 | 模板、示例数据、左图右卡、阅读/编辑路由 | 负责人确认分类和完整正文体验 |
| 2 数据底座 | 数据模型、Schema、SQLite迁移、资源目录、白名单会话 | 基础存储和对象权限测试 |
| 3 编辑闭环 | 块编辑、自动保存、版本、冲突、草稿恢复 | 故障用例通过，不丢字 |
| 4 导入检索 | Skill HTML+JSON/图片 → MD/DOCX → XLSX/XMind → ZIP；转换报告、搜索 | 逐种样例验收，不能一次宣称全格式完成 |
| 5 多视图一致性 | 分类投影、图谱关系、块定位、UI并排 | 重命名/移动/删除引用用例 |
| 6 导出备份 | 项目包、恢复、运维说明 | 在干净数据目录恢复通过 |
| 7 团队模式 | TLS、角色隔离、更新提示、可选评论 | 两人冲突、撤权、越权测试通过 |

每阶段交付可运行构建、启动说明、样例包、已知限制、测试记录。不在此预估无依据的固定天数；实际工期根据实现团队和高级编辑优先级确定。

## 2. 功能验收

- [ ] 上传 → 预览 → 归属 → 分类 → 全文 → 编辑 → 保存 → 搜索定位全流程完成。
- [ ] 模板生成所有规范章节；旧资料可保持结构，未分类和缺章明确显示。
- [ ] 卡片、图谱、目录、完整正文引用同一 ID；改标题/移块不失联。
- [ ] 收起关系图后能连续阅读整篇文档；编辑返回阅读保留位置。
- [ ] UI图片可放大，与控件说明对应；红点在对应页面下。
- [ ] 中文输入、粘贴、表格、图片、链接、撤销重做均有样例。
- [ ] MD相对图片恢复；缺图、损坏文件、不支持格式有可见反馈。
- [ ] DOCX标题、正文、图片、基础表格可读取；转换损失提示且原件可下载。
- [ ] XLSX工作表可切换，无缓存公式显示未计算；XMind原件和配图可用。
- [ ] 项目包导出再导入后正文、资源、分类、关系一致。
- [ ] Skill HTML+JSON 导入保留正文、稳定 ID、图示源数据与附件引用；同名不同文档不覆盖，过期 baseRevision 不覆盖新内容。
- [ ] 策划卡片和图谱没有完成状态、完整度、验收或待确认事项入口；游戏运行状态与技术保存反馈正常。

## 3. 保存与并发验收

- [ ] 刷新及重启服务后已确认保存内容仍在。
- [ ] 断网、磁盘满、服务器失败不显示成功且保留未提交内容。
- [ ] 保存途中继续输入、响应延迟/重试不覆盖后续输入或生成重复修订。
- [ ] 两人同版本编辑，后提交者收到409且能保留、比较、手动合并。
- [ ] 恢复历史产生新版本，保留操作人与来源版本。
- [ ] 关闭未保存页面出现提示；强制关闭后可选本地草稿能按身份隔离恢复。
- [ ] 在线阅读者收到更新提示；正在编辑的页面不被远端内容直接替换。

## 4. 安全验收

- [ ] 前端产物、项目包、普通日志中不存在白名单认证材料或会话值。
- [ ] 无会话不能读正文、资源、搜索摘要、导出或历史。
- [ ] 阅读者伪造写请求仍被拒绝；修改URL、资源ID、projectId不能跨项目读取。
- [ ] 禁用账号、移除成员后会话及已打开页面后续请求失效。
- [ ] 恶意HTML、危险链接、路径穿越ZIP、解压炸弹、宏与外部实体样例被阻断/清洗。
- [ ] 备份和资源目录不能作为静态URL访问。
- [ ] 本机默认仅监听回环；跨站请求不能绕过写请求校验；团队TLS不要求绕过警告。

## 5. 性能基线

保留原计划的 100 份文档、500 个关系节点、600 张图片。补充至少一篇长文、大表格、多图文档，记录真实大小、块数和图片分辨率。测试报告记录设备/浏览器、数据大小、冷/热启动及重复次数。

建议目标（待实测确认，不是承诺）：在验收机器本地环境，已授权项目热搜索 p95 ≤ 1秒；常规文档打开到可读 ≤ 2秒；图谱聚焦当前系统交互无持续卡顿；保存反馈 p95 ≤ 1秒（不含防抖等待和文件上传）。超标先定位数据库、渲染或图片问题，不通过减少测试数据掩盖。

## 6. 交付证据

每项写明通过/失败/未测、构建版本、操作步骤、截图或日志位置及缺陷编号。“方案已写”不等于“功能已实现”。本次仅完成方案文档，以上复选框均保持未验收。
