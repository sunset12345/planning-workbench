## 配置协议注意点

本案 `Const` 纵向填写；主表使用 `##var / ##type / ##comment` 三行声明头。列表用 `|`，组合字段用 `:`，嵌套候选用括号分组；部分 ID 自身含冒号，候选权重从最后一个冒号拆分。不要无差别按冒号切分。

类型包括 `int`、`bool`、`float`、`map,string,int`、`list,MapDifficultySettings` 等，开放时间是含时区字符串。后续确认需补足单位、空值、边界及子字段含义，不擅自换导表格式。
