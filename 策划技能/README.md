# 策划技能

这套 Skill 用于理清当前功能需求，覆盖修订记录、XMind、功能逻辑、配置字段、逐页 UI、多语言、音效，以及后续红点和业务打点。

正式策划案默认统一使用 Google 文档：正文和字段表可编辑，UI 图逐页嵌入；功能导图及配置结构图使用 XMind 源文件，正文放预览和源文件超链接。XMind 修改后需同步正文预览。用户另指定格式时按其要求。

| 内容 | 入口 |
| --- | --- |
| 可编辑技能正文 | [SKILL.md](game-feature-planning/SKILL.md) |
| 可套用模板 | [功能策划案模板](game-feature-planning/assets/功能策划案模板.md) |
| 详细规范 | [交付细则与检查](game-feature-planning/references/交付细则与检查.md) |
| 文档与图示格式 | [Google 文档与图示规范](game-feature-planning/references/Google文档与图示规范.md) |
| 当前玩法参考 | [当前案子参考](game-feature-planning/references/当前案子参考.md) |
| 分发文件 | [game-feature-planning.zip](发布包/game-feature-planning.zip) |

调用示例：

> 使用 $game-feature-planning，基于当前方案按统一格式整理 Google 文档策划案，补齐 UI 逻辑和配置字段，导图及配置结构图附 XMind 源文件链接和预览，未明确的规则在对应位置简短标注。

`game-feature-planning/` 是项目中的可编辑源文件；本机已安装副本位于 `~/.codex/skills/game-feature-planning/`，两者在本次整理时已同步。后续修改应从项目源文件开始，再同步本机安装副本并重新生成发布包。ZIP 是分发快照，不是编辑入口。

实案检查报告归属具体玩法，位于[玩法评审记录](../策划案/搜打撤远征融合玩法/评审记录/功能需求检查与补充草案.html)。
