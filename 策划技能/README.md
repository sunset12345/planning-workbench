# 策划技能

这套 Skill 用于理清当前功能需求，覆盖修订记录、可编辑导图、功能逻辑、配置字段、逐页 UI、多语言、音效，以及后续红点和业务打点。

默认面向研发阅读：优先说明类型、单值/list及数量约束、计算公式和UI状态；具体奖励与数值放配置附件或折叠示例。

正式策划案默认使用 HTML：正文、UI 和字段表集中阅读，图示保留节点与连线源码及页内编辑入口；美术、UI、特效需求分别交付独立 Excel 并以超链接引用。可附 HTML 演示。

`game-feature-planning/` 是项目中的可编辑源文件；本机已安装副本位于 `~/.codex/skills/game-feature-planning/`，两者在本次整理时已同步。后续修改应从项目源文件开始，再同步本机安装副本并重新生成发布包。ZIP 是分发快照，不是编辑入口。
